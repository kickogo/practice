# 快速排序（Quick Sort）：核心思想与通俗解读
快速排序是「分治思想」的经典应用，由计算机科学家 Tony Hoare 发明，是工业界最常用的排序算法之一（平均时间复杂度最优）。它的核心特点是**原地排序**（空间复杂度低）、**平均时间复杂度 $O(n\log n)$**（最坏 $O(n^2)$，但可通过优化避免），比冒泡/插入/选择排序（$O(n^2)$）效率高一个量级。

## 一、快速排序的核心思想（3句话讲透）
快速排序的本质是「**找基准、分两区、递归处理**」，通俗理解像「分蛋糕」：
1. **选基准（Pivot）**：从数组中选一个元素作为「基准值」（比如选第一个/最后一个/中间元素/随机元素）；
2. **分区（Partition）**：遍历数组，把**小于等于基准**的元素放到基准左边，**大于基准**的放到右边，最终基准会落在「正确的排序位置」；
3. **递归处理**：对基准左边的子数组和右边的子数组，重复「选基准+分区」步骤，直到子数组长度为1（天然有序）。

### 举个生活例子（新手秒懂）
比如对数组 `[9,3,7,5,6,4,8,2,1]` 排序：
- 选基准：选中间元素 `6`；
- 分区：把小于6的放左边 `[3,5,4,2,1]`，大于6的放右边 `[9,7,8]`，基准6的位置固定；
- 递归：分别对 `[3,5,4,2,1]` 和 `[9,7,8]` 重复上述步骤，直到所有子数组只剩1个元素。

## 二、快速排序的关键步骤（可视化）
以数组 `[9,3,7,5,6,4,8,2,1]` 为例，完整流程：
```
初始数组：[9,3,7,5,6,4,8,2,1]
1. 选基准：6（中间位置）
2. 分区后：[3,5,4,2,1] 6 [9,7,8] → 6的位置固定
3. 递归左区间 [3,5,4,2,1]：
   - 选基准：4 → 分区后 [3,2,1] 4 [5] → 4的位置固定
   - 递归左区间 [3,2,1]：选基准2 → 分区后 [1] 2 [3] → 2的位置固定
   - 右区间 [5]：长度1，无需处理
4. 递归右区间 [9,7,8]：
   - 选基准：8 → 分区后 [7] 8 [9] → 8的位置固定
最终排序：[1,2,3,4,5,6,7,8,9]
```

## 三、快速排序的核心特性
### 1. 时间复杂度
- **平均情况**：$O(n\log n)$（每次分区能把数组分成大致相等的两部分）；
- **最坏情况**：$O(n^2)$（比如数组已排序，选第一个元素作基准，分区后一边为空）；
- **优化方案**：选基准时用「随机基准」「三数取中」（选首/中/尾的中位数），避免最坏情况。

### 2. 空间复杂度
- **原地排序**：$O(\log n)$（递归调用栈的深度，平均情况）；
- 非原地实现（额外数组）：$O(n)$（不推荐，失去快速排序的优势）。

### 3. 稳定性
- 快速排序是「不稳定排序」（分区时交换操作可能打乱相等元素的相对位置）；
- 比如数组 `[2, 1, 2]`，选第一个2作基准，分区后可能变成 `[1, 2, 2]`，但两个2的原始顺序可能改变。

## 四、快速排序的C++实现（最简版，新手易理解）
```cpp
#include <iostream>
#include <vector>
#include <algorithm> // std::swap

// 分区函数：返回基准元素的最终位置
int partition(std::vector<int>& arr, int left, int right) {
    int pivot = arr[right]; // 选最右侧元素作基准（简单易实现）
    int i = left - 1;       // 小于基准的区域边界（初始在左边界外）

    // 遍历[left, right-1]，划分小于/大于基准的区域
    for (int j = left; j < right; ++j) {
        if (arr[j] <= pivot) { // 小于等于基准，划入左区域
            ++i;
            std::swap(arr[i], arr[j]);
        }
    }
    // 把基准放到正确位置（i+1是基准的最终下标）
    std::swap(arr[i+1], arr[right]);
    return i + 1;
}

// 快速排序递归函数
void quick_sort(std::vector<int>& arr, int left, int right) {
    if (left >= right) return; // 子数组长度≤1，无需排序

    int pivot_idx = partition(arr, left, right); // 分区，获取基准位置
    quick_sort(arr, left, pivot_idx - 1);        // 递归处理左区间
    quick_sort(arr, pivot_idx + 1, right);       // 递归处理右区间
}

// 封装函数（对外提供简单接口）
void quick_sort(std::vector<int>& arr) {
    if (arr.empty()) return;
    quick_sort(arr, 0, arr.size() - 1);
}

// 打印数组
void print_array(const std::vector<int>& arr, const std::string& desc) {
    std::cout << desc << ": ";
    for (int num : arr) {
        std::cout << num << " ";
    }
    std::cout << std::endl;
}

// 测试
int main() {
    std::vector<int> arr = {9,3,7,5,6,4,8,2,1};
    print_array(arr, "排序前");
    quick_sort(arr);
    print_array(arr, "排序后");
    return 0;
}
```

### 运行结果
```
排序前: 9 3 7 5 6 4 8 2 1 
排序后: 1 2 3 4 5 6 7 8 9 
```

## 五、快速排序 vs 其他排序（新手对比）
| 排序算法   | 平均时间复杂度 | 空间复杂度 | 稳定性 | 特点                     |
|------------|----------------|------------|--------|--------------------------|
| 快速排序   | $O(n\log n)$   | $O(\log n)$| 不稳定 | 效率最高，工业界首选     |
| 冒泡排序   | $O(n^2)$       | $O(1)$     | 稳定   | 简单但效率低             |
| 插入排序   | $O(n^2)$       | $O(1)$     | 稳定   | 小规模/近乎有序数组高效  |
| 选择排序   | $O(n^2)$       | $O(1)$     | 不稳定 | 交换次数少，效率低       |

## 总结
快速排序的核心可以浓缩为3个关键点：
1. **分治思想**：把大问题拆成「基准左区间+基准右区间」两个小问题，递归解决；
2. **分区核心**：通过一次遍历将数组分成两部分，基准落到正确位置；
3. **效率关键**：基准的选择决定性能（随机/三数取中可避免最坏情况）。

它是面试/工程中最常考、最常用的排序算法，理解其「分区」逻辑是掌握快速排序的核心，相比冒泡/插入/选择排序，快速排序的「分治」思路是效率提升的根本。
